# Playluma generated key art

All nine originals were generated with the built-in ImageGen mode. The supplied design screenshot was used only as a mood reference. No generated image copies PlayStation logos, controller symbols, platform trademarks or recognizable game artwork.

Landscape originals have responsive JPEG derivatives in `responsive/`. The Playluma icon also has header, favicon, home-screen and manifest sizes in `assets/` and `images/favicon/`. Earlier social crops are stored in `assets/` at 1200 × 630; the two new game pages use their crop-safe landscape art directly for social previews.
